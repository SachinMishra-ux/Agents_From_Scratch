Why does this Python code look so long?

When a human makes a slide in PowerPoint, you drag a box with your mouse, click the paint bucket to color it, and type text inside. Python does not have a mouse!

So to draw any item on a slide (a badge, a title, a card, or a footer), Python repeats the exact same 4 tiny commands over and over:

1. Place a Box (using 4 inch numbers): box = slide.shapes.add_shape(SHAPE, left, top, width, height)
2. Color the Box: box.fill.fore_color.rgb = RGBColor(20, 30, 52)
3. Put Text Inside: p = box.text_frame.paragraphs[0] → p.text = "Hello"
4. Pick Font Size & Color: p.font.size = Pt(14) → p.font.color.rgb = TEXT_WHITE
