3 Understanding Command(goto=..., graph=Command.PARENT)

1. Subgraph Isolation

In the diagram, notice each agent is its own complete box with __start__ -> model <-> tools -> __end__. Tools execute inside that agent's local subgraph.

2. Why Command.PARENT?

A tool cannot directly jump to a sibling agent on its own. Setting graph=Command.PARENT signals the top-level parent orchestrator to switch nodes.

3. Multi-Turn Routing

When a user answers in turn 2, the graph starts at the top __start__ node. The conditional edge checks active_agent and resumes with whoever holds control!

// How LangGraph handles handoffs at runtime
return Command(
    goto="underwriter",                          // Next agent to run
    graph=Command.PARENT,                         // Directs the parent graph
    update={                                       // State mutations
        "loan_application": loan_app,
        "active_agent": "underwriter",             // Remembers active agent
        "messages": [
            ToolMessage(content="Application submitted", tool_call_id=tool_call_id),
            AIMessage(content="[System Handoff]: Routing to Underwriting...")
        ]
    }
)
