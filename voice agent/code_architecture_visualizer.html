1. What is PCM?

Pulse-Code Modulation (PCM) is uncompressed digital sound. Unlike MP3/AAC, PCM has zero decompression lag, enabling sub-second voice AI conversation.

2. 48kHz vs 16kHz

Mac microphones record at 48,000 samples/sec. Speech models only need 16,000 samples/sec. Resampling cuts 66% of network bandwidth.

3. Int16 Bit Depth

Browser captures Float32 decimals [-1.0, 1.0]. In convertToInt16, we multiply by 32,767 to produce signed 16-bit integers [-32768, +32767].

4. ws.send() Pipe

Transfers raw pcm16.buffer binary directly across the persistent WebSocket tunnel to FastAPI with zero HTTP overhead.
